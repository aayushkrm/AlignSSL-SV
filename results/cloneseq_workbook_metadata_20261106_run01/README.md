# CloneSeq-SV supplement: workbook metadata

The [protocol and result](../../docs/research/2026-11-06-cloneseq-supplement-inventory.md)
specify the separate pre-download scope. The 18,466,636-byte archive was
verified against the publisher MD5, and both named members passed ZIP CRC
checks on extraction. The archive, workbook, legends document and extracted
legend text remain outside Git in `runs/cloneseq_workbook_metadata_20261106_run01/`.

`metadata.json` contains only sheet names, declared dimensions and a hash of
the locally retained legend text. No worksheet data rows were inspected.
The receipt records commands, source and local hashes.
