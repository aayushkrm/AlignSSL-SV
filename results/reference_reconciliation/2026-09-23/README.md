# HGSVC/IGSR reference-difference evidence bundle

This is a mirrored, small-artifact record of SLURM jobs `1598069` (failed before comparison) and `1598070` (completed). It contains 18 original count-only JSONs, 18 complete `*_base_differences_full.json` summaries, 18 coalesced BED3 maps, the 194-contig M5 comparison, source/checksum notes, and both logs. All **59 mirrored files** were checked byte-for-byte by comparing local SHA-256 hashes with their cluster originals. `VERIFICATION.json` records SHA-256 hashes and checks the paired JSON/BED invariants using [`scripts/verify_reference_difference_map.py`](../../../scripts/verify_reference_difference_map.py). The verified total is **13,923,221 unequal bases in 152 intervals** across 18 contigs.

The left HGSVC no-ALT FASTA is publisher-MD5 verified, with local SHA-256 `90f1dcdb28a81ac26f6eaa1afc285e7ec459c195c2134fb25af0e82be2f11729`. The right IGSR FASTA was streamed from the URL stored in each full JSON; its full-content hash was **not** captured during this job. `SHA256SUMS` records the staged HGSVC FASTA and index hashes, not an IGSR FASTA hash. The source sequence files themselves are not in Git.

The BEDs contain only **unequal bases**, not all ambiguous sequence. Both references have shared-`N` positions between some intervals. These BEDs are therefore not callable masks or sufficient exclusions for SV truth, read alignments, or caller candidates. See the [reconciliation](../../../docs/research/2026-09-23-reference-reconciliation.md) and [independent review](../../../docs/research/2026-09-23-scientific-review-reference-map.md) before using this bundle.
