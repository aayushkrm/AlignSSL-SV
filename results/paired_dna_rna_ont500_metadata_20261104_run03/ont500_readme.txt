README — updated 2025-11-04
This directory contains long-read sequencing data from the first 500 samples generated by the 1000 Genomes Project Long-Read Sequencing Consortium (1kGP-LRSC).
All files have passed internal quality control but may represent unpublished data that are still undergoing analysis. Contents and directory structure will be updated as additional data types and processing results become available.
Metadata
•	1kGP_LRSC_500_ONT_Metadata.tsv — sample-level metadata including demographic information and sequencing chemistry
Primary Data
•	UNALIGNED_BAMS/ — unaligned, basecalled long-read data for each sample 
•	ASSEMBLIES/ — de novo genome assemblies for subsets of samples, generated with different assembly pipelines:
o	FLYE for the first 100 samples
o	Hifiasm for R10 flow-cell samples
o	Shasta-HapDup for the complete 500-sample cohort
Reference-Aligned Analyses
•	ALIGNED_TO_HG38/ and ALIGNED_TO_CHM13/ — analyses aligned to the GRCh38 (hg38) and T2T-CHM13 v2.0 reference genome, respectively, including:
o	reference-aligned BAMs and assemblies
o	alignment statistics
o	small variant (SNV/indel) calls
o	structural variant (SV) calls
o	tandem repeat annotations and related analyses
