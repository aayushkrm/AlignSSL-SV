## Why inversion and centromere do not advance
A localized exchange tract differs from migration, but this does not establish
a consequential native failure. Sperm switch tracts do not label past origins;
events/Mb/meiosis cannot be inserted as lineage migration/generation.
Synthetic origin truth tests a model, not real-origin attribution.
Native [ferromic recurrence training](https://github.com/SauersML/ferromic/blob/0aa57692c4f49c676a790757aa25d930191c7b34/recurrence/simulate.py) is an affirmative overlap control.
For centromeres, two active arrays can share one outer kinetochore.
Cross-sectional chr21 copy heterogeneity is not observed derivative loss.
Balanced/unbalanced lines differ in donor, derivative and ploidy; many cells
do not remove these confounds or create independent donor replication.
The [2025 ROB study](https://www.nature.com/articles/s41586-025-09540-8) already provides assembly and activity assays.
A paper crosswalk could close that feasibility gate, but ranks below the specific
ecDNA native-control test. It is not a second selected next action.

## One highest-value action: establish the exact native ecDNA counterexample
Use only the reported [Cycle Extractor case](https://doi.org/10.64898/2026.03.10.710955)
and its [official examples](https://github.com/AmpliconSuite/CycleExtractor).
First fix its exact provenance, input graph/copy values, expected two cycles,
truth source, and observed read/subwalk constraints. These are NOT verified here.
Do not invent a graph, infer truth from its output, or create favorable reads.
If the exact case or its expected structures cannot be established, STOP this gate.
A published synthetic case can test an algorithmic claim only; its generating
truth cannot replace independent biological structure or cell-assignment labels.

The narrow falsifier asks whether native CoRAL or Decoil separates that fixed
case using compatible observed evidence. [CoRAL](https://pmc.ncbi.nlm.nih.gov/articles/PMC11529860/) already uses subwalk constraints;
[Decoil](https://pubmed.ncbi.nlm.nih.gov/39111816/) already deconvolves overlapping bulk mixtures.
Check native input requirements before treating them as executable challengers.
Give each method the same permitted evidence; labels remain evaluation-only.
Do not infer subwalks from truth or penalize a method for lacking required input.
If either resolves it, reject the alleged unresolved gap.
If all fail, ask whether the observations distinguish the two-cycle solution
from the merged solution. Equal aggregate copy does not settle this question:
copy identifies amounts; a distinguishing observed subwalk may identify linkage.
Without distinguishing evidence, STOP an algorithmic rescue of this case.
If evidence distinguishes it yet native methods fail, retain only a residual
algorithmic failure, pending independently labeled biological relevance.
Repeating the known merge, auditing every source, or adding a synthetic wrapper
is not a publication contribution; future-work prose establishes no new gap.
