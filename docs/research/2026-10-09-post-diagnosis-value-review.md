## What would make a native mechanism test informative

These are proposal criteria, not a selected experiment or data-read approval:

1. Specify a consequential allele-level failure and independent allele/read support, with fixed sample, raw-read provenance, reference, platform and executable versions. A final-VCF residual or benchmark-added label alone is not the failure ground truth.
2. Verify exactly what each native artifact records and omits. The proposed stage must be observable well enough to distinguish no seed, assembly failure, allele/genotype failure and later filtering. An undocumented or incomplete candidate trace cannot turn absence into a causal stage label.
3. Predeclare one discriminating intervention and matched control that isolate the proposed mechanism. Keep downstream processing and evidence fixed; expose changed read selection or computation rather than attributing all gains to seeding. Compare against the closest documented seeded/consensus/native recovery approach, using compatible inputs. Standard annotation seeding plus assembly is not a new contribution merely because it repairs this project's interface.
4. Require allele-appropriate recovery and specificity checks, not only region overlap or geometry. State a concrete consequential falsifier: if the supported allele is already represented upstream but only disappears later, reject a candidate-seeding failure explanation; if the isolated intervention cannot recover it, reject the proposed sufficiency claim. If a close native control already achieves the same rescue, that challenges distinct added contribution even if the local mechanism is real.
5. Review the scientific value, complete prospective account, controls, pinned commands and one-shot stop rules BEFORE any data experiment. A positive single-locus contrast may establish local feasibility; it does not establish general prevalence, robust performance or publication-worthiness. Stronger claims require a separately justified design, not post hoc escalation.
