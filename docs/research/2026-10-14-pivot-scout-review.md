## Why the complex-event proposal is not the next cheap test

Generic sequence equivalence, phased local comparison and component joining
are occupied tasks in the scout's own sources. A distinct long-event path
question remains plausible, but missing path evidence is UNKNOWN, not a
demonstrated evaluation failure. The selection recipe does not name an event,
and producing a new caller path could be substantial work rather than a small
source falsifier. Do not call a candidate with invented or swapped components
an observed native-caller failure.

The cited vcfdist warning is over50GB for some larger variants. It does not
establish lack of support, an algorithmic limit at10kb, or inability to run on
the reported256GB cluster. Any later claim must separate documented scope,
actual input compatibility, measured cost and correctness. No run is needed
to recognize that the present scout has not shown a counterexample.

Coding-gene overlap and a changed intact-transcript count are possible impact
readouts, not necessary entry conditions for useful event-path research.
An informative path error or information limit can matter without a clinical
outcome. Failure to find one first coding event would close that finite search,
not falsify the broader complex-SV opportunity. Keep a broader pivot available.

## Proposed synthetic placement sweep: STOP before implementation

Recommendation: zero compute on this proposed sweep as a selector of a further
study. Main's supplied full-Discussion reading explicitly acknowledges real-SV
confusion/reference bias and expects sufficiently supported real events to have
non-symmetric reads. That is not a guarantee that every true foldback placement
survives. I did not independently refetch the Discussion in this decision.

A true inverted-duplication/foldback allele is distinct from balanced INV/S10.
However, feeding exact two-segment PAFs to the native filter measures its
conditional geometry rule after imposing the alignment representation. Truth
of the synthetic allele does not make a read's geometry distinguishable from
an artifact. If true/artifact controls supply identical decision-relevant PAF
features, equal classifications are expected, not evidence of a new failure.

| Sweep outcome | What it would establish |
|---|---|
| Some true placements flagged | A position-dependent tradeoff already acknowledged by the supplied Discussion |
| Every eligible placement flagged | A blind region for this fixed length/allele/PAF construction; not failure of the population expectation about sufficient non-symmetric reads |
| No true placement flagged | Compatibility of this construction with the rule; not general sensitivity or specificity |

The inclusive200..800 range enumerates601 placements in1,000-bp windows.
That count is not a distribution of real fragment starts, lengths, artifacts
or allele support. Its flagged fraction cannot establish event-level evidence
loss, native mapping behavior or caller performance. Contiguous-reference and
artificial-foldback controls check the software route but do not supply those
missing scientific comparisons. Exhaustiveness within the grid does not
resolve this limitation. No outcome above presently chooses a distinct next
scientific question, so the low compute cost alone does not justify the run.

This could later serve as an implementation/geometry control for an already
specified discriminating study; it is not that study's falsifier now. No
additional metadata audit or full-study prerequisite is requested. Preserve
the acknowledged tradeoff and compare stronger questions. This STOP is not
a biological null or a field-wide conclusion. Only this addendum was written;
no implementation, new source search, data analysis or job was performed.
