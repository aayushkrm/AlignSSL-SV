# Alternative independent-donor SV cohorts for AlignSSL-SV

**Research date:** 2026-09-23. Scope: DEL candidate filtering at ≥50 bp. This is a source-readiness assessment, not a model-performance result.

**Bottom line:** no new-donor source is verified end-to-end for assembly/long-read truth, donor-specific callable negatives, public Illumina alignment, reference compatibility, and donor separation. HGSVC3 is closest but has a reference mismatch to its available short-read CRAMs and no donor-wide callable BED in the inspected v1.0 release. “Unknown” below means not established by inspected first-party material, not proof that no such file exists elsewhere.

## Bounded alternative-source check

HGSVC3 remains the nearest source to a multi-donor pilot because 63 of its 65 truth IDs have exact public CRAM-index matches and its VCF sequence digests match a verified no-ALT FASTA. This does **not** clear its reference or callability gates: the [complete difference map](2026-09-23-reference-reconciliation.md) identifies unequal bases but is not a safe mask, and no donor-wide confident-negative BED has been verified. Resolve those gates before treating HGSVC3 as selected.

For an **alternative-source feasibility check**, intersect HGSVC2's 32 VCF columns with the CRAM index, pedigree, and prior-donor ledger; inspect one CRAM header and the source's donor-specific callability evidence. This reuses an existing callset but is not a measured minimum in bytes, runtime, or cost. Do not remap or bulk-transfer one donor merely because metadata match; stop if reference identity or callable-negative provenance fails. HPRC HG00097 is a derivation route if released truth sources fail the same gates.

## Interpretation limits

- Filter truth to DEL with `abs(SVLEN) >= 50` (or document the END rule). A VCF’s missing site, `.` genotype, or common repeat mask is not a confident negative; negatives require that donor’s callable regions and adequate flanks.
- Freeze donor partitions before analysis, remove prior-donor overlap, group known relatives, and check kinship where feasible. Compare SVs representation-aware; assembly truth is not exhaustive, especially in repeats and unresolved regions.
- No candidate calls were evaluated and no positive result is claimed. Existing detail: [HGSVC3 callability audit](2026-09-23-hgsvc3-callability-audit.md), [reference reconciliation](2026-09-23-reference-reconciliation.md), [reference audit](2026-09-23-hgsvc3-reference-audit.md).
