# Gene conversion and complete structural haplotypes: source screen

9 October 2026. Main source check; not an experiment or selected direction.

## Finding

Do not select a generic gene-conversion, inversion-origin or whole-locus
phasing project on these sources. Existing work already makes substantial
use of structural haplotypes, gene exchange and haplotype-specific dosage.
The check finds no supported residual that merits an empirical launch yet.
This is not a biological null or a claim that all relevant data are absent.

The peer-reviewed 17q21.31 study assigns inversion status from 1,271 tag SNPs
and combines it with read-depth estimates for KANSL1 duplications. It expressly
uses a rarity assumption when two copy allocations have the same diploid
dosage, and does not phase NSF duplications. Those are stated interpretation
limits, not evidence that its calls are wrong. A consequential error would need
actual case-resolved evidence, a useful outcome and a strong current control.
Its PCA switch patterns do not uniquely distinguish double crossovers from
gene conversion. The study also warns that its simple selection estimate
neglects demographic history. [Primary study](https://www.nature.com/articles/s41467-026-73174-1).

The newer gene-flux preprint already assigns haploid alpha and beta-prime copy
number using allele balance as well as depth, and looks for recombinant
haplotypes. A generic proposal to add this signal would duplicate its method.
Its single-cell sperm reads require dbGaP access (phs001887.v1.p1); All of Us
uses the Controlled Tier. Public 1KGP/HGDP and assembly portals are listed, but
this check did not establish an exact usable case or independent prediction/
evaluation contrast. [Exact-v1 methods and data statement](https://www.biorxiv.org/content/10.64898/2026.09.28.755014v1.full).

The older [inversion-recurrence screen](2026-10-07-inversion-recurrence-territory.md)
already rejects a broad exchange-aware origin classifier because current native
controls model exchange. Main read that entire note. This new check extends
the gene-flux source read into Methods; it does not reopen that proposal.
