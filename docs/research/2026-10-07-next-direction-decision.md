## Why acquisition should not get another toy pass

The clinical report is a useful failure case, not a labeled acquisition task.
It reports three possible region-C structures after finding all breakpoints,
and a need for linkage across a block exceeding 400 kb. It does not identify
one alternative as truth. It also reports segmental-duplication ambiguity in
region O. These are different sources of uncertainty.
[Clinical primary article, version identified in the record as PMC13171962.1](https://pmc.ncbi.nlm.nih.gov/articles/PMC13171962/).

Three separate requirements remain:

1. **Physical opportunity.** Some molecule or chain of independently phased
   links in the actual library must distinguish the alternatives. A controller
   can retain a molecule; it cannot make that molecule longer. The reported
   block length is not proof that every possible solution requires one read
   longer than 400 kb. Nor does it prove that shorter, overlapping phase links
   exist. More local depth helps only if it supplies missing informative links.
2. **Decision-time signal.** Prefixes must predict useful linkage beyond the
   coverage, end, length and mapping signals used by native policies. A prefix
   shared by informative and uninformative molecules gives no selection power
   between them. Whole-read linkage or the final topology cannot enter the
   decision. AEONS accepting unmapped reads also blocks an easy novelty claim
   based on rescuing all initially unmapped molecules.
3. **Real cost and useful outcome.** Finding more bridges is not itself a
   clinical benefit. Observational full reads do not reveal pore occupancy,
   rejection/reload delays or the molecules that would follow a different
   action. Native simulator pseudo-time is a model. An equal accepted-base or
   read-count comparison cannot establish an equal instrument-time benefit.

A synthetic example with favorable prefixes can pass by construction. An
example with no possible bridge can fail by construction. Neither establishes
a residual native-method failure or a useful new contribution. A finite
synthetic calculation could later reject a precisely stated claim, but there
is no selected claim here worth another implementation gate.

Main's separate simulation audit is ongoing. Main reports that
`process_batch_aeons_sim` passes full-FASTQ `read_lengths`, obtained before
decisions, to `rl_dist.update` after rejection truncation. Whether the actual
length-distribution implementation then changes subsequent decisions is still
being checked. This is a possible hidden rejected-length feedback path, not
established performance impact or target-label leakage. This decision did not
inspect that implementation or write its note/tests.

For any future diagnostic, declare the information available at each decision.
Completed accepted reads and observed rejection prefixes are available;
unobserved remainders of rejected molecules are not. A length prior estimated
from a separate, declared source is different from hidden full lengths fed
back from the evaluation stream. If the audit confirms such feedback, report
its effect on a fair comparison before drawing scientific conclusions. A
simulator correction is engineering work, not a new biological foundation,
and does not reopen acquisition or authorize experiments.

The 12-sample, 169.8-GB clinical EGA collection is controlled access. The two
roughly 199-GB ENA archives are uninspected microbial archives, with no ready
human topology labels or verified timing inputs. Access is not approved and
neither source is an experiment-ready substitute.
[EGA dataset](https://ega-archive.org/datasets/EGAD50000001821),
[BOSS ENA study](https://www.ebi.ac.uk/ena/browser/view/PRJEB51967).
Do not make acquiring those inputs the next action.

## Stronger biological question

**Does long-range order or phase change a disease-relevant gene effect when
the detected junctions and copy number are held fixed?**

The useful contrast is between a rearrangement that retains a functional
transcript and one that disrupts it, or between two structures with different
causally tested regulation of the same gene. The unit of evidence is a
functional allele, not an extra breakpoint, graph edge or annotation score.
This separates the need to solve a structure from the need to explain disease.

This question has stronger potential consequence than acquiring more reads
for an unresolved picture. It is **not novelty-cleared**. SVAN/SVA already
analyze insertion architecture and gene transductions; SAVANA/Severus already
use junction and haplotype structure; the clinical study already establishes
the unresolved reconstruction problem. Ordinary gene disruption, fusion
annotation, regulatory rewiring and structure prediction are existing work,
not contributions to claim here. A new study would have to isolate a
topology-dependent functional effect beyond those native analyses. This
bounded record does not establish that such a case exists or that functional
prior art leaves it unaddressed. No field-wide absence claim is made.

## One next science action: a consequence contrast on region C

**Make one manual, phenotype-blind consequence table for all three published
region-C topologies.** Use the paper's reported structures and annotations;
do not request reads, infer one structure as truth, or build a tool. This is a
test of whether the unresolved structure is biologically worth resolving.
The next action is analysis of a named real case, not a data-availability search.

Use the following fixed protocol before viewing the phenotype as a selection
criterion:

| Step | Required comparison | Stop rule |
|---|---|---|
| Check the contrast | List the junction identities/orientations and copy number for each alternative. Locate the difference in order or phase. | If the alternatives instead differ in an already measurable local junction or copy state, they do not test the proposed conditional question. |
| Compare gene effects | For every gene affected by any alternative, compare intact coding path, promoter-to-exon connection, fusion transcript path and allelic phase. Inspect all three alternatives by the same rule. | If established gene consequences are identical, stop region C as the anchor for this question. Do not seek a favorable gene or alternate case within this one-case gate. |
| Distinguish prediction from biology | Record any proposed enhancer/promoter reassignment separately from a transcript disruption. Name the tissue and exact functional measurement that could reject that prediction. | A changed drawing, genomic distance or contact prediction alone does not pass. If no specific functional contrast can be stated, stop. |

Incomplete published coordinates or phase information yield **UNRESOLVED**,
not a pass. Do not fill the missing structure with an assumed pathogenic
configuration. Failure of this one case rejects its use as an anchor; it does
not reject topology effects throughout biology. Success establishes a reason
to test a functional contrast, not the true patient topology or a new method.

The smallest biological discriminator, if that table reveals a specific
contrast, is one locus with two matched structures and an independent
allele-specific transcript readout in a relevant cell context. For a proposed
regulatory cause, add a targeted rescue that removes or restores the predicted
regulatory connection while controlling gene dosage and genetic background.
The contrast must exceed effects of the edits themselves; a generic reporter
with no native long-range context is insufficient. Prediction of the affected
transcript and its direction must be fixed before the readout is revealed.
Patient phenotype or measured expression must never be used to choose a
topology and then reused as validation of that choice.

No functional experiment is authorized by this note. Such an experiment
would require a verified native-prior-art gap and a concrete, reviewable assay
design before any costly work. The immediate paper-only contrast can kill
the premise without claiming a known length limitation as a publication.
