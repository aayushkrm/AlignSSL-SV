## Main's primary-source correction

Using Exa's primary-page reader, main reads the Breakinator Methods and
Discussion, not only the search summary. The Methods map HG002 reads to
maternal and paternal HG002v1.0.1 assemblies separately, select by alignment
score and prefer a greater-than-95%-contiguous alignment over a chimeric one.
An inversion encoded in that personal reference need not supply the split
geometry expected against GRCh38. Coordinate liftover cannot recreate that
counterfactual alignment. This defeats the proposed public-table endpoint,
not the broader artifact question. [Primary article](https://pmc.ncbi.nlm.nih.gov/articles/PMC12870357/).

The same Discussion already acknowledges reference bias and real-event/artifact
confusion. A constructed midpoint sweep would demonstrate a known geometry
tradeoff, not real placement distributions or event-level sensitivity. The
independent reviewer recommends STOP before implementing that synthetic study.
Native ABI controls in the selected real-input screen have a different purpose:
they verify the software route, not a scientific filter-safety claim.
