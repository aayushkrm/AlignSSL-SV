## What the proposed positive would establish

The [frozen decision](2026-10-09-public-paired-falsifier-decision.md) defines a
project prioritization assumption: remove an allele from complete-transcript
follow-up when the fixed DNA policy supplies no qualifying coding path.
It explicitly says this is not a promise by VEP or LiftOn. The
[maintained HG002 review](2026-10-10-public-paired-falsifier-review.md#hg002-the-useful-question-and-the-main-fault-to-prevent)
also states that LiftOn does not exhaust all possible splice paths.

Here, a resolved P1 negative means that **none of this fixed policy's retained
paths meets the endpoint**, after local sequence, phase, copy and path-accounting
checks. It does not mean that DNA cannot encode a complete transcript.
K > 0 means that attributable RNA supplies such a path despite that policy
result. This can reject the project's proposed exclusion rule. It need not
contradict the annotation tool, an accepted biological model, or actual practice.

| Claim or practice | What a valid K > 0 would test | Current evidence and limit |
|---|---|---|
| LiftOn reconstructs useful coding annotations through homology and ordinary rescue | A missed observed path in this source and policy | A miss is compatible with the policy's known search and retention limits. No exhaustive-path claim was established. |
| VEP HIGH or a coding SV implies functional loss | Presence of a same-termini complete coding RNA sequence | The endpoint permits internal sequence changes. It does not prove retained protein function, overturn a consequence label, or refute functional loss. |
| A real workflow discards these alleles from RNA follow-up because P1 is negative | An incorrect exclusion, with a concrete downstream cost | No such consequential workflow, applied to this exact endpoint, was identified in the read evidence. The rule is currently proposed by this project. |
| The overlapping SV causes the observed transcript structure | Allele attribution | Phase and artifact checks do not distinguish that SV from linked variants or other causes. Causation is not the endpoint. |
| Allele-resolved DNA/RNA integration is new | A carefully controlled instance of that integration | The paired study already integrates phased DNA and RNA. Standard calling, assembly, annotation and custody are not a new contribution. |

This is an evidence limit, not a claim that no researcher ever makes an
incorrect exclusion. Nor is a counterexample to a newly proposed rule
automatically uninteresting. It becomes important when the rule represents a
real decision, or the observation reveals a separately supported new mechanism.
Neither bridge has been established for this pilot.

An unknown residual can be tested prospectively. A pre-identified failure,
second donor, new model or guaranteed publication is not required. The
investment needs a worthwhile question whose possible answers have a defined
scientific use. The current protocol's best-case conclusion can remain a miss
by a policy that was never an exhaustive transcript predictor.

Independent value could come from a documented consequential exclusion with a
reproducible correction; a new, independently supported molecular mechanism;
or a defined evaluation resource that exposes an important failure on an
actual task. The present protocol establishes none of these in advance.
A phase-validated unannotated isoform alone does not select one. A benchmark
would need its actual task and contribution defined; a biological mechanism
would need evidence beyond allele attribution. Do not quietly add those claims
to the current sequence endpoint.

**Scientific reopening condition:** identify one concrete claim or applied
practice from already available primary evidence, explain why this unchanged
endpoint can test it, and state the useful conclusion if K = 0 and if K > 0.
The value must survive the explanation “ordinary annotation incompleteness.”
Do not create the practice by declaring that this project will use the rule.
No further broad literature survey, new library, endpoint change or favorable
outcome is commissioned here. If that bridge cannot be made, pivot the research
question. The governing publication objective takes priority over this pilot.
